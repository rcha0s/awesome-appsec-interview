# Doc format: prose-first opener with numbered clickable references

The 33 AI/agent docs (batch 1a/1b, docs 32-66) shipped with a "wire-first" opener: title, then wire-level example, then a 3-8 row invariants table, then spec anchors, then finally a `## Mental model` paragraph. Comparing that shape against doc 28 (GraphQL, prose-first) showed the wire-first opener forces the reader through ~60 lines of structural material before reaching a paragraph that says what the topic actually is. Prose-first serves fast interview reload better because the mental-model paragraph is what a reader needs first, and the wire example plus invariants table are more valuable as a distilled cheat-sheet *after* the mental model has been loaded.

We are locking a prose-first order for every doc going forward: title, blockquote mental-model paragraph, `## Quick reference` block containing only the wire example and the invariants table, then `## How it works` and the rest. The standalone `## Spec / RFC anchors` block is removed; every spec citation moves into the numbered `## Sources` list at the bottom (the invariants table's Source column names the spec in plain text and the numbered ref carries the URL). The `## Interview-grade nuances` bullet list is removed as a duplicate of `## Interviewer probes` (probes already carry both a mid-level answer and a principal answer per question).

Inline citations render as `<sup>[[N]](#refN)</sup>` in the Attack and Defense sections only, and each `## Sources` entry ships with an `<a id="refN"></a>` anchor so refs are clickable on GitHub. Attack techniques and Defense items keep visible sub-headings (`### N. <name>` and numbered defenses), but the four-rubric coverage inside each technique (mechanism, payload, OOB confirmation, escalation) is woven into prose rather than exposed as bolded sub-heads. Reviewer agents still enforce the rubric against a checklist.

This decision drives a retrofit across all 33 AI/agent docs (canary on doc 53 first, then fan-out) and an update to the `add-appsec-topic` skill so future single-doc adds emit the new shape. The full locked section list and glossary live in [CONTEXT.md](../../CONTEXT.md).
